vim-js2coffee
=============

[![Open in Hanzo](https://hanzo.app/badges/open-in-hanzo.svg)](https://hanzo.app/dev/open?repo=github.com/zeekay/vim-js2coffee&ref=master&action=open) [![Edit with Hanzo](https://hanzo.app/badges/edit-with-hanzo.svg)](https://hanzo.app/dev/open?repo=github.com/zeekay/vim-js2coffee&ref=master&action=edit)

Adds `Js2Coffee` command which converts the current JavaScript buffer to CoffeeScript. Utilizes the excellent [js2coffee](http://js2coffee.org/) (so make sure to `npm install -g js2coffee` first).
